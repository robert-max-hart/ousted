# Ousted: notes for Claude

A colony management game in the style of Banished, built in **Godot 4.7.2** with the **GL Compatibility** renderer.
The focus is realistic agriculture, and there is no combat.

- `docs/scenario_ideas.md` holds brainstormed scenarios (serious, outrageous, and ones that need a new mechanic); none is built or scheduled.
- `docs/plan.md` is the expanded plan: system designs, architecture, milestones M1 to M8, open questions and prototype findings. **Read it before starting work.**

## Code conventions (match these)
- GDScript is **fully typed**, indented with **4 spaces** and **ends statements with semicolons**. Classes are declared as `class_name X extends Y;`.
- Each file starts with a header comment block (`# ---- / # Name / #  description`). Sections are separated with `# --------------------------------`.
- Data definitions are static dictionaries in `scripts/data/defs.gd` for now. The plan is to move them to `.tres` files later.
- The scene tree is built in code from `World._ready()`, and `scenes/main.tscn` is a single node.

## Architecture (short version)
- Autoloads: `GameClock` (time, speed, and hour/day/season signals), `Weather`, and `Stock` (read-only colony totals summed over storage buildings; goods live in `Building.stored`, with per-building reservations).
- `World` (`scripts/world/world.gd`) owns the terrain, the `NavGrid` (an AStarGrid2D wrapper), the per-cell occupancy arrays (`occupant`, `node_at`), soil fertility, all entities and the lighting. It's reachable anywhere as `World.instance`.
- Citizens (`Pawn`) run a `Task`, which is a list of steps (MOVE, WORK, ACT) with `on_cancel` and `on_end` callbacks. Tasks come from `JobManager.choose_task()` in this priority order: needs, then dropping off what they carry, then sleep at night, then their profession's work, then general labor, then idling.
- **File size (decided 2026-10-25): keep every script under 1000 lines.** Task making is split by theme: `JobManager` (core, targets, logistics, construction, gathering, farming, idle) extends `TaskBase` (shared: `world`, `count`, `workers_at`, `in_radius`, `harvest_node_task`), and holds `needs` (`NeedsTasks`), `school` (`SchoolTasks`) and `production` (`ProductionTasks`: woodcutter, tools, inputs, blacksmith, mining), which also extend `TaskBase`. They must not hold a reference back to `JobManager`: RefCounted cycles leak ("resources still in use at exit"). The sky, lighting, water and precipitation moved from `World` into `WorldVisuals` (`world.visuals`, a child node). **Split of 2026-10-30** (world.gd was 1414 lines, hud.gd 1168, building.gd 1068): the work moved into static helper classes that take the owner as the first argument, with a thin delegate left behind in the owner so callers did not change: `StartSite` (finding the start spot, rocks and ore around it, founding the colony), `WorldSave` (`serialize` and `restore_entities`), `RoadWork` (staked roads, channels, irrigation flow), `WaterReach` (the Water overlay's distance map), `TreeOrders` (the Plant tool's marks), `Relocation`, `Citizens` (leaving, dying, bodies, newcomers) and `GroundPiles` in `scripts/world/`; `HudBuild` (builds the panels) in `scripts/ui/`; `BuildingVisuals` (body, door, chimney, bridge deck, fit to footprint) in `scripts/entities/`. New code for those areas goes in the helper, and a new public function there needs a delegate in the owner only if other files call it. Next candidates if files grow: `defs.gd` (803), `pawn.gd`, `job_manager.gd`.
- Clicking the terrain is handled by marching a ray through the heightmap (`Terrain.raycast`), with no physics colliders.

## Running and testing
Godot is not on PATH. On both workstations the binary is `/home/rmh/godot/Godot_v4.7.2-stable_linux.x86_64`.
```
godot --headless --path . --import                                   # after pulling, registers classes
godot --headless --path . --fixed-fps 60 res://tests/sim_soak.tscn   # fast-forward run with a daily colony report
godot --path . res://tests/screenshot.tscn -- <out_dir>              # windowed: dawn/noon/dusk/night PNGs
```
Run the soak test after any simulation change, and the screenshot test after visual changes (then view the PNGs). **The whole suite:** loop over `tests/*.tscn` skipping the `*_shot`, `*probe`, `screenshot`, `title_*` and `ui_flow*` ones, run each headless with `--fixed-fps 60` and look for `FAIL` or `SCRIPT ERROR` lines (about 10 minutes; a test that ends with an "RID allocations leaked" error is normal). The map seed changes every run, so a test may fail on one seed only: **tests must not place things at a fixed offset from the Town Hall** (the river can be there): use `TestSite.near(world, prefer, area)` and `TestSite.spot(world, size, prefer)` from `tests/test_site.gd`. New tests need a `.tscn` next to the script (copy any, change the script path) and `godot --headless --import` once so the class names are registered.

## Gotchas learned so far
- **Windowed tests over ssh:** use `DISPLAY=:1` with `--display-driver x11` (the user's graphical session; check `ls /tmp/.X11-unix` and `who`). Headless runs of `*_shot` tests print `save_png` errors: ignore them. **`git checkout scripts/ui/player_tools.gd` after an import wipes uncommitted edits to it**; retab it with a script instead (leading tabs to 4 spaces).
- **Screenshot test with no Wayland session** (an ssh or tty shell): run it as `DISPLAY=:1 godot --display-driver x11 --path . res://tests/screenshot.tscn -- <out_dir>` (an X server was on `:1` on this workstation). It now places a finished Mine and Blacksmith and shows their inspectors at the noon and dusk shots.
- The inspector panel scrolls when it is taller than the screen (`_info_scroll` in `hud.gd`).
- **`godot --import` also rewrites `scripts/ui/player_tools.gd` with tab indentation** (the editor's indent setting; reproducible, only that file). After an import run `git checkout scripts/ui/player_tools.gd` if you did not change it, or set the editor's Text Editor > Behavior > Indent > Type to Spaces.
- **`godot --import` rewrites `project.godot`** and strips the `renderer/rendering_method="gl_compatibility"` line. Check `git diff project.godot` after any import and restore it with `git checkout project.godot` before committing.
- The soak test (`tests/sim_soak.gd`) runs only `DAYS = 6` by default, not a full year. Raise it for a year-long check.
- Git identity is set per repo (`robert-max-hart`). The history was rewritten once on 2026-10-23 to fix the old author on the first commits, so any older hashes are gone. The remote `origin` is `git@github.com:robert-max-hart/ousted.git` (SSH key `~/.ssh/id_ed25519`); the branch is `main` and was first pushed 2026-10-26. Push only when asked.
- **Freeing a building that a citizen's task callback still references** logs "Lambda capture was freed". To avoid it, `World.remove_building` ends every task whose `target` is that building before freeing it. Any new task that captures a Node in a callback must set `task.target` to that node.
- Don't write a multi-line lambda followed by another argument (`f(func(): ..., "x")`). Assign the lambda to a local variable first.
- In GL Compatibility, lighting saturates quickly. The sun is around 0.6 energy and ambient around 0.3 (`SUN_KEYS`, `MOON_KEYS` and `LIGHT_KEYS` in `world_visuals.gd`), and fog is very light. Materials using vertex colours set `vertex_color_is_srgb = true`.
- On HUD controls with anchors, set the `offset_*` properties, not `position`. The bottom bar needs `grow_vertical = GROW_DIRECTION_BEGIN` or it ends up off-screen.
- `@warning_ignore("integer_division")` goes on the function, not on a variable inside it.
- Performance: about 45 fps at 1600×900 with shadows on an Intel UHD 620.
- **A new model needs its reduced twin:** run the generator in `tools/` a second time with `--low` (`python3 tools/make_plants.py --low`, same for buildings and the others) and import, or the **Reduced** model detail setting fails on it (found 2026-11-02 by `model_detail`; test `model_sets` now checks every model has a twin).
- **A pasted-over merge or a big section replace can swallow neighbouring sections of this file** (it happened once on 2026-10-30): after editing CLAUDE.md, check `grep -n '^## ' CLAUDE.md`.
- **`World.alive(o)` needs a `removed` property** (buildings, nodes, pawns, bodies and `TreeOrder` have one). A `Merchant` has none: use `is_instance_valid`.
