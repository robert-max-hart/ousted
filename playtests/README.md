# playtests/

Local playtest material: the user's notes after a play session (`playtest_notes.txt`, `playtest_2.txt`, ...) and any stray save files
(`autosave.sav` is an old save from before the 160-cell map, it no longer loads). **Everything here except this file is git-ignored**
(see `.gitignore`), so notes can be dropped in freely and never end up in a commit. New notes go here, not in the repo root.

How they are used: when the user asks to work through a playtest, read the newest file here, list what it asks for, build it, and record
what was done in `CLAUDE.md` (the sections named "Playtest ... fixes") rather than in the note itself.
